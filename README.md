# Control de Almacén
Sistema de control de almacén hecho con Google Sheets y Apps Script.

## Archivos
- Codigo.gs: lógica del servidor (materiales, movimientos, solicitudes, equivalencias)
- Index.html: interfaz web

## Instalación
1. Crear una hoja de Google Sheets
2. Extensiones → Apps Script
3. Copiar Codigo.gs, Index.html y appsscript.json
4. Implementar como aplicación web
